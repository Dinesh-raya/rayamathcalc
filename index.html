Speed maths practice for bank exams

Build calculation speed and accuracy with unlimited generated questions across 17 topics. Everything runs in your browser; nothing is saved, uploaded or tracked. Close or refresh the page and the current drill disappears — that is deliberate.

How it works

  1. Pick a topic or mixed practice, set difficulty and the session type.
  2. Answer with the keyboard (Enter submits) or tap the on-screen options.
  3. Review every question afterwards — with the correct answer and a shortcut.
  4. Retry your mistakes or run a fresh set of the same topic.

Difficulty changes the patterns used, not just the size of the numbers. Every answer shown is computed when the question is built and checked again before it is displayed.

What this tool does and does not do

  • Generates questions live — no fixed question bank, so sessions can be repeated indefinitely.
  • Keeps the current drill and its analysis in memory only. There is no history and no saved progress.
  • Sends nothing anywhere: no analytics, no accounts, no external requests.
  • Shows a verified correct answer for every wrong, skipped and timed-out question.
